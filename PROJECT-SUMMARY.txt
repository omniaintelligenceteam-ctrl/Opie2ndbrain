DEPLOYMENT
================================================================================

Development (5 minutes):
  1. node opie-relay.js              (Terminal 1)
  2. npm run dev                     (Terminal 2)
  3. http://localhost:3000           (Browser)

Production on Vercel (15 minutes):
  1. git push to GitHub
  2. Import to Vercel dashboard
  3. Set env: NEXT_PUBLIC_OPIE_RELAY_URL
  4. Deploy
  5. Keep relay running 24/7 (systemd service)

See DEPLOYMENT.md for detailed instructions.
